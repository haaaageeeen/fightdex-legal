Your Fightdex account is ready. Go back to the Fightdex app and sign in — this page has nothing else for you to do.

Why a web page and not the app?

Fightdex does not register a custom link scheme. Doing so would mean any other app on your phone could claim the same link if the verification behind it were ever misconfigured, and the only thing it would buy is skipping this page. Signing in and resetting a password both use a six-digit code typed into the app, so this confirmation link is the one email in Fightdex that opens a browser at all.

If you did not create a Fightdex account, you can ignore this — an unconfirmed address is never used for anything.

Dein Fightdex-Konto ist fertig. Geh zurück in die Fightdex-App und melde dich an — auf dieser Seite gibt es nichts weiter zu tun.

Warum eine Webseite und nicht die App?

Fightdex registriert kein eigenes Link-Schema. Das würde bedeuten, dass jede andere App auf deinem Telefon denselben Link beanspruchen könnte, falls die dahinterliegende Prüfung je falsch konfiguriert wäre — und der einzige Gewinn wäre, diese Seite zu überspringen. Anmeldung und Passwort-Zurücksetzen laufen beide über einen sechsstelligen Code in der App. Dieser Bestätigungslink ist die einzige E-Mail in Fightdex, die überhaupt einen Browser öffnet.

Falls du kein Fightdex-Konto erstellt hast, kannst du das ignorieren — eine unbestätigte Adresse wird für nichts verwendet.
